Digital Twin Operations
High Level Design

Luồng demo biến IFC/BIM từ mô hình thiết kế thành giao diện vận hành: xem campus nhiều tòa, mở IFC chi tiết, tìm thiết bị, mô phỏng telemetry, sinh cảnh báo, tạo incident/work order và điều phối technician.

React + Vite Three.js / GLB preview That Open + web-ifc Mock Operations Data Ollama / Qwen intent parser Alert / Incident / Work Order

1. System Architecture

Điểm chính khi demo: không gộp nhiều IFC thành một file lớn. Campus dùng GLB preview nhẹ, khi chọn tòa mới load IFC thật bằng That Open/web-ifc. Dữ liệu vận hành được tách ra khỏi BIM dưới dạng asset registry, telemetry, incident và work order.

2. Operations Workflow

Search + LLM

Rule parser xử lý câu rõ ràng. Ollama/Qwen chỉ dùng để parse intent JSON khi cần. Kết quả vẫn query từ asset registry.

Spatial + Route

Spatial search dùng khoảng cách x/y theo mét. Campus route đi theo road graph; indoor route vẫn là corridor mock mức MVP.

Operations

Alert tạo incident runtime, incident tạo work order, dispatch technician theo specialty + distance + availability và có ETA sửa chữa.

3. Current Technology Stack

Đang dùng trong demo

  • React 18 + Vite: UI, dev server và mock API local.
  • Three.js: campus 3D, GLB preview, road, marker technician, route line.
  • That Open Components + web-ifc: load IFC chi tiết, pick object, locate theo GlobalId.
  • GLB preview pipeline: convert IFC sang GLB nhẹ cho màn campus.
  • Ollama/Qwen 2.5 1.5B: optional natural language intent parser.
  • JSON mock DB: asset registry, technician, floorplan, site layout, incident seed.

Chưa phải production

  • Chưa có MQTT broker/device platform thật.
  • Chưa persist incident/work order xuống backend database.
  • Chưa có PostGIS/spatial index thật cho truy vấn quy mô lớn.
  • Chưa có routing engine đầy đủ theo tường, cửa, thang máy, khu vực cấm.
  • Chưa có LOD/tile streaming cho thành phố lớn.
  • LLM hiện gọi local Ollama, chưa có cache/queue/rate limit production.

4. Scale-Up Direction

Khi lên 100/1000 user: không để mọi query gọi LLM. Nên dùng rule-first, cache, queue/rate limit, và chỉ gọi Qwen/API cho câu khó. Asset search và spatial search nên chạy bằng database/spatial engine, không để LLM tự tìm trong toàn bộ asset.
